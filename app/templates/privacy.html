개인정보 처리 안내

웹 서버 접속 로그에는 접속자의 IP 주소, 요청 URL, User-Agent 등 개인을 식별할 수 있는 정보가 포함될 수 있습니다. {{ app_name }}은 이 정보를 다음과 같이 다룹니다.

1. 처리하는 정보

사용자가 직접 업로드한 웹 서버 접속 로그 파일의 내용입니다. 회원가입이 없으며, 업로드한 사람에 대한 정보는 따로 수집하지 않습니다.

2. 처리 목적

업로드한 로그에서 공격이 의심되는 접속을 탐지해 결과 화면을 보여주는 목적으로만 사용합니다.

3. 보관 기간

업로드한 로그는 디스크에 저장하지 않습니다. 분석하는 동안에만 메모리에 머무르며 분석이 끝나면 즉시 폐기됩니다. 분석 결과 역시 서버에 저장하지 않으며, 결과 화면을 닫으면 다시 볼 수 없습니다.

4. 외부로 전달되는 정보

업로드한 로그 파일 자체는 외부로 보내지 않습니다. 다만 분석 품질을 위해 다음 정보가 외부로 전달될 수 있습니다.

  • 검색봇 진위 확인: User-Agent에 검색엔진 봇이라고 적힌 IP(최대 30개)에 대해, 진짜 검색엔진의 주소인지 확인하려고 DNS 조회를 합니다. 이때 해당 IP가 DNS 서버로 전달됩니다.
  • AbuseIPDB 평판 조회 (선택): 업로드할 때 직접 선택한 경우에만, 탐지된 IP(최대 {{ abuse_max }}개)를 AbuseIPDB에 보내 신고 이력을 조회합니다. 로그의 다른 내용은 보내지 않습니다.
  • 국가·통신사 정보: 서버에 저장된 DB-IP 데이터 파일로 조회하며 외부로 전송하지 않습니다.

5. 서비스 운영 기록

서비스 안정성과 남용 방지를 위해 이 사이트에 접속한 IP와 시각이 웹 서버 기본 접속 기록과 요청 횟수 제한 기능에 일시적으로 남을 수 있습니다.

6. 이용자 유의사항

본인이 운영하거나 분석 권한을 받은 서버의 로그만 올려 주세요. 타인의 로그를 권한 없이 올리는 것은 관련 법령에 위반될 수 있습니다.
